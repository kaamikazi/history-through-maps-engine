# Brand tokens

`tokens.json` is copied unchanged from the channel identity repo
https://github.com/kaamikazi/History-C (brand/tokens.json, commit d740964).

That repo is the source of truth. If a colour changes there, copy the new tokens.json here.
The brand styles (styles/lamplight.json, styles/paper.json) read their colours from this file
using names like "@ink" or "@territory".
